# Mac16 自主开发执行约定

2026-11-20 用户要求：开发目标为16GB Mac，日常开发全委托AI，评估是否需要小队。
本地开发替代原文Windows开发；8GB目标部署验收保持待决定，不冒称本机测试覆盖8GB。
推荐一个Leader会话、独立Developer会话、独立QA会话，顺序调度。
Release角色可按需独立会话。初始执行并发1，负载实测后最多2个轻任务。
构建/E2E/迁移串行，合同与迁移采用唯一Owner。
环境准备不启动44项正式开发，也不修改原产品语义与安全门槛。
用户要求无人参与日常开发；原计划要求真实人业务审批和最终签出。
后续需将验收条款明确改为AI受托审核，或将真实人签署列为外部未完成。
不得将AI测试角色当作真实人的批准，不得凭空生成真实CPQ事实。
现有Codex ChatGPT登录仅证实开发CLI可用，不能当作产品服务端API凭据。
