## 证据格式

实际 `docs/release/release-manifest.json` 至少包含 releaseId、repo/commit/build digests、schema/migration/config版本、发布环境与时间、source基线与contractHashes、scope决议、真实 CI run与测试artifact、Self Project baseline及知识Manifest refs、实际部署和恢复证据、所有追溯行的状态、缺陷/例外及实际审批身份。不得用假ID或本合同样例填充。在验收矩阵中记录 `not_started/in_progress/blocked/implemented/verified/accepted/deferred_approved`；`implemented`不等于`accepted`。只有同时满足原行为/确认替代验收、真实测试与知产证据、必要部署后，QA/BA联合签出可标accepted。延期图形专项保留源要求、Owner实际签出以及替代语义测试，此时才可标deferred_approved。未批准、缺证据、关键阻断不允许标通过。旧源文件不被覆盖。
