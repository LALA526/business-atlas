# Business Atlas｜技术实现与完整产品交付基线 T1.0

编制：2026-11-19。适用：Architecture Leader、开发 Agent、独立 QA、安全与发布负责人。状态：**技术实施候选基线，可作为正式开发输入；尚未经生产环境验证或最终签署。** 本包不是生产程序，不以设计文件、模拟数据、接口骨架或本地合同校验代替完整交付。

## 1. 最终交付目标（不允许缩减为 MVP）

按照 P1.0 建成可运行、可审阅、可持续维护、可部署的 Business Atlas。项目独立身份与领域语言；人可阅读、批注、审核 AI 组织的需求、规则、设计与证据；项目权威知识经批准/发布后约束后续人和 Agent；变更追溯到业务语义、职责与实际实现；外部 Agent 经授权 API/MCP 获得任务上下文、调查真实仓库、提交结果及知识提案；真实 CI 对账；多人并发、权限、版本和恢复；Self Project 真实知识持续更新。最终交付一套完整产品，不以局部纵切停止。

**技术默认决策：** ASP.NET Core / EF Core 10（稳定补丁锁定）、React 19 + TypeScript + Vite、PostgreSQL 17、OIDC、模块化单体、数据库 Job/Outbox、私有文件存储、真实外部模型和 Agent 接入。单一公开 Web/API/MCP 入口，独立 Worker 进程，同一 DB；不强制 Neo4j、向量库、Redis、Temporal、OpenFGA、消息中间件或自研编程调度平台。默认部署目标 Mac mini M1 8GB，容器 ARM64；资源目标必须实测，不是已测结果。

## 2. 权威性和变更纪律

1. P1.0 是产品语义输入（含 U/R/X 分类）；此包是其技术实现约定。旧 BA/V1.2 未被本包悄悄覆盖；见 `01_技术实施/01_目标架构与范围.md` 和 `03_开发执行/requirements-trace.csv`。技术选择在授权内采用默认；产品/业务/高风险安全决策必须由对应 Owner 批准。P1.0 的被批准程度、实际 CPQ 事实与正式图形范围尚未证实。
2. 冻结后的机器合同（OpenAPI、Schema、注册表、DDL迁移、任务合同）优先于重复描述；文档说明其语义。任何差异由合同 Owner 先修合同、更新消费者/测试、记录 ADR，不允许 Agent 私自解释。附录旧协议为输入，不能以旧图形 API 或旧 Schema 覆盖新约定。
3. 当前推荐正式 T1 产品不实现自动绘图、画布、布局和图形导出；流程、状态、条件、证据、原始图作为资料仍保留。4 个历史专用绘图要求建议延期、3 个改为文字语义、1 个保持表达选择；在 G0 完成正式范围签署。无结论可独立完成非争议工作，不冒充已批准。
4. 真实 CPQ 规则、凭据、部署目标检查、外部模型账号未提供；只在授权后使用。合成样例明确 EX，不能污染真实知识。初始 README、研发任务和 CI 记录需进入 Self Project 候选，首次真实审核后发布。

## 4. 工作顺序

先读本页、Leader指令、架构/数据/权限合同，再按任务 DAG 领取。架构 Leader 确定公共契约和 migration owner，不能兼任全部功能开发；独立开发 Agent 按明确路径、合同实施；独立 QA 从目标规范而非开发者自述验收。按依赖连续执行到完整交付，不每阶段停下要求人分配工作。若事实/权限缺失，只阻断相关分支并记录，其他独立工作继续。

当前源码尚未创建，DAG 使用冻结的目录/文件职责规划，不虚构已经存在的分支、PR、代码或测试日志。本包接口和数据库是供实施的首选合同；必须在真实 DB、运行环境及真实模型环境执行相应验证，并登记必要修订。最终产品必须有实际运行、代码、测试、部署、知识审批与对账证据。
